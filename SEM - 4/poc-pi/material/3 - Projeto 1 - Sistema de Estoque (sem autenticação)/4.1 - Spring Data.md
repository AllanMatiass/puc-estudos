No Spring Data, temos alguns métodos padrões, vou citar **ALGUNS** deles: 

r = repository.
`r.save(T)` -> Salva um novo dado, onde T é a entidade do repositório.

`r.delete(T)` -> Deleta um dado do banco pela entidade
`r.deleteById(UUIDDoObjeto)` -> deleta um dado do banco pelo id
`r.existsById(UUIDDoObjeto)` -> verifica se o ID daquele objeto existe, retornando um *boolean*
r.findById(UUIDDoObjeto) -> encontra e retorna  o objeto (pode ser nulo, pois é Optional<>, tem que validar).

sobre o findById(), temos alguns submétodos que ajudam bastante na redução de if's no código:

`r.findById(id).orElseThrow(() -> new Exception("T não existe."));` -> O nome é autoexplicativo, se não encontrar pelo ID, dá um exception dizendo que T não existe.

`r.findById(id).orElse(new T(param1, param2, etc));` -> Apesar de redundante, você pode colocar um "substituto" caso não encontre pelo id.

`r.findById(id).isEmpty();`  -> Verifica se o objeto está vazio, então, não foi encontrado.
`r.findById(id).isPresent();` -> o contrário do isEmpty
`r.findById(id).get();` Pega a entidade de fato. Mas, tem que validar se ele existe antes. De preferência, usando os métodos acima.
